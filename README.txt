MANBAZAR-I DEVELOPMENT BLOCK — WEBSITE TEMPLATE

Files:
- index.html : Home page
- notices.html : Notices page
- style.css : Maroon responsive design
- script.js : small search/year functionality

How to use:
1. Upload all files to any static hosting provider.
2. Replace placeholder government data with verified information.
3. Replace the demo hero image URL if desired.
4. Add official PDFs to a documents folder and link them from the pages.
5. For an actual Government of West Bengal official website/domain, obtain the required departmental authorization and use the approved government domain/hosting.

This package is a design/template and does not itself constitute an official government website.
